Install Tracker (required for real users)

Add this single line before the closing </body> tag on each site. 

<!-- Nexora / Discipline tracker -->
<script src="PATH-TO/tracker.js" data-site="nexora" async></script>

<!-- For Discipline page use: data-site="discipline" -->
<!-- For main dashboard use:  data-site="dashboard"  -->

You can host tracker.js on the same GitHub Pages repo, on Vercel, or any CDN. After adding it, every page load will increment the live counters above.

Security Analysis

  • HTTPS + HSTS — Both hosts enforce HTTPS with long-lived HSTS headers.
  • No Content-Security-Policy — Add a CSP header (GitHub Pages cannot set headers — use a <meta http-equiv> CSP or put Cloudflare in front) to reduce XSS risk.
  • Missing headers — X-Content-Type-Options, Referrer-Policy, Permissions-Policy, frame protection not present.
  • No mixed content — All scripts load over HTTPS.
  • CDN scripts lack SRI — Three.js & GSAP from cdnjs should include integrity hashes.
  • No third-party trackers by default (good for privacy). This tracker is opt-in and cookie-free.

Errors & Quality

  • All three pages return HTTP 200.
  • No error monitoring (Sentry etc.) — JS exceptions are invisible.
  • Heavy client libs (Three.js + GSAP) — watch Core Web Vitals on mobile.
  • Viewport meta present on Nexora.
  • This dashboard itself auto-refreshes counters every 15 seconds.

Browser Analysis Script

Paste this into the browser console on any of your pages for an instant local security / quality report. 

(() => {
  const report = {
    url: location.href,
    title: document.title,
    https: location.protocol === 'https:',
    scripts: [...document.scripts].map(s => s.src || 'inline').filter(Boolean),
    hasCSP: !!(document.querySelector('meta[http-equiv*="Content-Security"]') ||
              document.querySelector('meta[name*="Content-Security"]')),
    viewport: !!document.querySelector('meta[name="viewport"]'),
    externalScripts: [...document.scripts].filter(s => s.src && !s.src.includes(location.host)).map(s => s.src),
    imagesWithoutAlt: [...document.images].filter(i => !i.alt).length,
    linksWithoutText: [...document.links].filter(a => !a.textContent.trim() && !a.getAttribute('aria-label')).length
  };
  console.table(report);
  console.log('%cNexora Analysis Report', 'color:#22d3ee;font-size:14px;font-weight:bold');
  console.log(report);
  return report;
})();
