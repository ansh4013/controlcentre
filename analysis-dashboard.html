Security Analysis

  • HTTPS enforced
    Both Vercel and GitHub Pages serve over HTTPS. HSTS present: strict-transport-security: max-age=63072000 (Vercel) and max-age=31556952 (GitHub).
  • No Content-Security-Policy (CSP)
    Neither site sends a CSP header or meta tag. This increases risk of XSS if any injected script appears. Recommendation: add a CSP (start with report-only) that allows your CDNs (cdnjs, three.js, gsap) and your own origin.
  • Missing security headers
    Observed headers lack: X-Content-Type-Options: nosniff, X-Frame-Options / frame-ancestors, Referrer-Policy, Permissions-Policy. GitHub Pages cannot set custom headers; use a meta CSP tag or put Cloudflare in front.
  • No mixed content
    All scripts and assets load over HTTPS (cdnjs.cloudflare.com, same-origin).
  • Third-party scripts
    Nexora loads Three.js + GSAP from cdnjs. Subresource Integrity (SRI) hashes were not detected. Recommendation: add integrity and crossorigin attributes to CDN scripts.
  • Access-Control-Allow-Origin: *
    Present on both hosts. Acceptable for public static sites; not ideal if you later add authenticated APIs.
  • No obvious analytics / tracking cookies
    No gtag, Facebook Pixel, or similar scripts found. Good for privacy by default.
  • Client-side only / static
    Sites appear fully static (no forms posting sensitive data observed in initial scan). Discipline is a habit tracker — ensure any future localStorage / backend storage does not leak PII without consent.
